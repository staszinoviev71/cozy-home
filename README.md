# 🏡 Уютный Дом (Cozy Home Companion)

> Персональное PWA-приложение и компаньон для двоих с поддержкой реального времени, интерактивными мини-играми, эмоциональным трекером настроения, списком покупок и виджетами One UI для смартфонов **Samsung Galaxy A54**.

---

## ✨ Основные возможности

### 🐶 Эмоциональный трекер & Альтер-эго
- **8 эмоциональных состояний:** Счастлив(а), Устал(а), Голоден(а), Грустно, Хочу вкусняшку, Ворчу, Уютно, Люблю.
- **Интерактивные персонажи (SVG):**
  - Любимый Корги 🐕
  - Брюнетка (жена) 👩🏻
  - Парень с мелированными прядями (муж) 👱🏼‍♂️
- Динамическая аура под цвет настроения и реактивная смена состояния партнёра в реальном времени.

### 🎲 Мини-игры для двоих («Супер-Рандомайзер»)
- **3D Кубик:** плавный физический бросок с трёхмерным вращением.
- **Колесо Фортуны:** интерактивная рулетка с динамической разбивкой от 2 до 6 секторов и приятной анимацией вращения.
- **Пользовательские вопросы и ответы:** возможность задать любой свой вопрос (например: *«Кто сегодня моет посуду?»*, *«Какой фильм смотрим?»*, *«Куда поедем на выходных?»*) и ввести свои варианты исходов.

### ⚡ Быстрые SOS-пуши
- Мгновенные уведомления партнёру в 1 тап.
- **13 категорий и эмодзи:** 🛒 Купи хлеб, ☕ Нужен кофе, 🏠 Я уже дома, ❤️ Скучаю, 💊 Зайди в аптеку, 🍕 Закажем пиццу и др.
- **Свой текст:** возможность отправить персональное экспресс-сообщение.
- Интерактивный баннер Heads-Up уведомления поверх экрана с кнопками быстрого ответа (*«Куплю!»*, *«Уже еду!»*).

### 🛒 Умный семейный список покупок
- Синхронизация отметок в реальном времени между обоими телефонами.
- Прикрепление фото упаковок товаров, чтобы не перепутать в магазине.
- Прогноз цикла расхода постоянных товаров (чай, фильтры, кофе).
- Режим «Я в магазине» со звуковым сигналом партнёру.

### 🍲 Рулетка ужинов «Что приготовить?» & Секретный Вишлист
- Случайный выбор блюд из семейной книги рецептов с авто-добавлением недостающих ингредиентов в список покупок.
- **Секретный вишлист:** если один партнёр отмечает подарок как купленный, получатель продолжает видеть его как сюрприз — спойлеры исключены!

### 📋 Паспорт дома
- База знаний квартиры в 1 тап: коды домофона, пароль от Wi-Fi, размеры фильтров для воды, контакты сантехника и УК.
- Моментальное копирование любого значения в буфер обмена.

### 🔄 Бесшовная синхронизация в реальном времени
- 6-значный семейный код сопряжения (например: `582910`).
- Двусторонняя облачная передача данных через защищённый WebSocket без необходимости сложной регистрации.
- Офлайн-кэширование через Service Worker.

## 🎨 Дизайн и эргономика
- **Liquid Glass 2.0:** глубокий AMOLED-черный фон (`#0B0E17`), адаптивное размытие (backdrop-filter), мягкие неоновые подсветки.
- Оптимизировано под экран 120Hz Super AMOLED смартфона **Samsung Galaxy A54**.
- Управление одной рукой (One UI Reachability) — все ключевые кнопки в нижней трети экрана.

## 🚀 Установка на Samsung Galaxy A54

### Способ 1: Прямая установка из браузера (PWA)
1. Откройте ссылку приложения в **Samsung Internet** или **Google Chrome**.
2. Нажмите меню (три точки или кнопка «Поделиться») ➔ **«Добавить на главный экран»** (или значок «Установить» в адресной строке).
3. Приложение установится как нативная программа с иконкой, полноэкранным режимом без адресной строки и поддержкой офлайн-работы.

### Способ 2: Сборка нативного APK через PWABuilder
1. Откройте [PWABuilder](https://www.pwabuilder.com/).
2. Введите URL опубликованного приложения (например, адрес GitHub Pages: `https://staszinoviev71.github.io/cozy-home/`).
3. Нажмите **Package for Android** ➔ скачайте готовый файл `app-release.apk` и установите на телефон.

## 🛠 Технологический стек
- **Frontend:** Vanilla TypeScript, Modern HTML5 Canvas & Web Components, CSS Modern Glassmorphism.
- **PWA:** Service Worker (`sw.js`), Web App Manifest (`manifest.json`), Offline Cache Storage API.
- **Real-Time Sync:** MQTT over Secure WebSockets (`wss://broker.emqx.io:8084/mqtt`), `BroadcastChannel` API.
- **Testing:** Jest, 77 unit & integration тестов (100% pass).
