# Cozy Home Companion v1.2.0: Реструктуризация, «Вместе», «Домик» и «Заметки»

> **Goal:** Комплексное развитие приложения «Уютный Дом»: реструктуризация навигации на 5 вкладок (Главная, Покупки, Вместе, Домик, Заметки), удаление 3D-кубика, внедрение кастомных групп заметок с таймером обратного отсчёта, объединение вишлиста с сюрпризом и копилки во вкладку «Вместе», и реализация 2.5D изометрического Домика Мечты с живым Коржиком и визуальным обустройством мебелью.

---

## Архитектура навигации (5 вкладок)

```text
[ 🏡 Главная ]    [ 🛒 Покупки ]    [ 💖 Вместе ]    [ 🏠 Домик ]    [ 📝 Заметки ]
```

---

## План по задачам (Task-by-Task)

- [x] **Task 1: Реструктуризация навигации и экспресс-правки**
  - Обновить нижний навбар: Главная (`#view-main`), Покупки (`#view-shopping`), Вместе (`#view-together`), Домик (`#view-house`), Заметки (`#view-notes`).
  - Перенести плашку «Я зашёл в супермаркет (есть 5 минут)» из Главной в раздел «Покупки».
  - Удалить 3D-кубик судьбы.
  - Перенести «Колесо фортуны» в самый низ вкладки «Вместе» с удалением дефолтных вопросов и добавлением чистого интерфейса для своих вариантов.

- [x] **Task 2: Вкладка «Заметки» (Кастомные группы + Напоминания с датами)**
  - Реализовать менеджер пользовательских групп («Домашняя аптечка», «Полезное/Дом», «Авто», «Контакты»).
  - Добавление, редактирование, удаление заметок с быстрым копированием значения в 1 тап.
  - Поддержка типа «Событие с датой / Напоминание» (дата, интервал напоминания, бейдж обратного отсчёта дней «Осталось N дней»).
  - Синхронизация заметок через WebSocket/Long-Polling.

- [x] **Task 3: Вкладка «Вместе» (Ужин + Вишлист подарков + Копилка на мечту + Колесо)**
  - Секция 1: 🍝 **Ужин** (рулетка, рецепты, голосование, перенос ингредиентов в список покупок).
  - Секция 2: 🎁 **Вишлист подарков с режимом сюрприза** (автор видит обычный список, партнёр может тайно забронировать покупку).
  - Секция 3: 🎯 **Копилка на мечту** (общие финансовые цели с прогресс-баром и взносами).
  - Секция 4: 🎡 **Колесо фортуны** (кастомные вопросы и варианты).

- [x] **Task 4: Вкладка «Домик» (2.5D изометрический Дом Мечты + Коржик + Мебель)**
  - Изометрический разрез комнат в стилистике Liquid Glass 2.0.
  - Живой Коржик внутри дома (гуляет по комнатам, спит на купленном коврике/диване, интерактивный тап с сердечками).
  - Переключатель освещения День / Вечер с тёплым светом из окон и камина.
  - Визуальные слоты мебели: купленные предметы физически появляются в комнатах.
  - «Лавка уюта» с лимитом 1–2 предмета в неделю и совместным подтверждением обоими супругами.
  - Уровни расширения дома (Lv. 1 Студия ➔ Lv. 2 Мансарда ➔ Lv. 3 Вилла).

- [x] **Task 5: Синхронизация Android Widget & Assets**
  - Обновить ассеты WebView в `android/app/src/main/assets/`.
  - Синхронизировать виджет Samsung One UI.

- [ ] **Task 6: Сборка релиза APK v1.2.0 и тестирование**
